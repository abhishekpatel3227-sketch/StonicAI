# Stonic AI — Android starter project

This is an original Android starter app using the requested name and a futuristic mobile assistant interface. It is not the official Stonic product and does not copy its proprietary code.

## Included in this starter
- Android app shell and dark futuristic interface
- Voice input using Android speech recognition (Hindi-India locale)
- Spoken replies using Android text-to-speech
- Local on-device memory for a remembered text
- Web search handoff to the phone browser

## Important current limitation
The chat currently uses simple local demo replies. A real conversational AI model, online research integration, background agent, and richer long-term memory are not connected yet. A free AI service may have usage limits and may require an account/API key. Do not put private API keys directly in a public app.

## Build an APK
1. Install Android Studio on a computer.
2. Open this `StonicAI` folder as an existing project.
3. Let Gradle sync complete (internet required to download Android build dependencies).
4. Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the generated APK location.

Package: `com.stonic.ai`  |  Minimum Android: 8.0 (API 26)
